# Lalasia - интернет магазин

## Запуск проекта

Установка зависимостей:

```bash
yarn
```

Запуск в режиме разработки:

```bash
yarn dev
```

Production build:

```bash
yarn build
```

Запуск production-версии:

```bash
yarn start
```

Проверка lint:

```bash
yarn lint
```
